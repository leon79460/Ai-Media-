# AI Media

Next.js 16 + React 19 + Tailwind CSS 4 project.

## Stack

- Next.js `16.2.6`
- React `19.2.6`
- Tailwind CSS `4.3.0`

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Tailwind Setup

Tailwind is enabled through:

- `app/globals.css` with `@import "tailwindcss";`
- `postcss.config.mjs` using `@tailwindcss/postcss`
